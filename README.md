# یار — دستیار تب جدید کروم

تب جدید فارسی و راست‌چین برای کروم: تقویم شمسی، آب‌وهوا و پیش‌بینی، نرخ ارز و طلا،
مبدل، اخبار، میان‌برها، کارها، یادداشت و تایمر تمرکز — **همه در یک صفحه، بدون اسکرول، بدون هیچ بخش هوش مصنوعی**.

## نصب

۱. آخرین نسخه را از [صفحهٔ Releases](https://github.com/AmirGhl/Yar/releases/latest) دریافت و باز کنید
   (یا مخزن را clone کنید: `git clone https://github.com/AmirGhl/Yar.git`).
۲. در کروم به `chrome://extensions` بروید.
۳. **حالت توسعه‌دهنده** (Developer mode) را روشن کنید.
۴. روی **Load unpacked** بزنید و همان پوشه را انتخاب کنید.
۵. یک تب جدید باز کنید.

از این به بعد یار خودش نسخهٔ تازه را از همین مخزن پیدا می‌کند و خبر می‌دهد.

کروم ۱۱۱ به بالا لازم است.

## قابلیت‌ها

| بخش | چه می‌کند |
| --- | --- |
| **امروز** | ساعت، تاریخ شمسی، آب‌وهوا و مناسبت روز — همه در یک کارت. کلیک روی آب‌وهوا، پیش‌بینی ۱۲ ساعته و ۶ روزه را باز می‌کند |
| **جست‌وجو** | هفت موتور، پیشنهاد زنده، تشخیص نشانی سایت، **پاسخ فوری** (حساب «۲۵×۴» و تبدیل «۱۰۰ دلار»)، **میان‌بر موتور** («!y عبارت») و جست‌وجوهای اخیر |
| **میان‌برها** | شبکهٔ ۱۲‌خانه‌ای؛ پرکاربردهای مرورگر + میان‌بر دستی، **قابل جابه‌جایی با کشیدن**. هر خانهٔ خالی خودش دکمهٔ افزودن است |
| **تقویم** | نمای ماهانهٔ شمسی، مناسبت‌ها و تعطیلات، تاریخ میلادی و قمری روز انتخابی، **یادداشت شخصی روی هر روز**، فاصله تا تعطیلی بعدی |
| **نوار نرخ‌ها** | دلار، یورو، سکه، طلا، **نقره (هر گرم)**، انس، بیت‌کوین، تتر و شاخص بورس — یک ردیف باریک پایین صفحه؛ کلیک = جزئیات، نمودار و هشدار |
| **پنل کناری** | کارها، یادداشت، اخبار، نشان‌ها، تایمر تمرکز، **مبدل ارز و تاریخ** و **سبد دارایی** در یک کنترل بخش‌بخش |
| **پالت فرمان** | `Ctrl+K`: فرمان‌ها، میان‌برها، نشان‌های مرورگر، حساب فوری، افزودن کار و جست‌وجو — از یک ورودی |
| **پاپ‌آپ** | نگاه سریع به ساعت، تاریخ، دما و نرخ‌ها + افزودن کار |

### تازه‌های نسخهٔ ۱٫۷ — به‌روزرسانی از گیت‌هاب

- یار هر ۶ ساعت (بی‌صدا، در پس‌زمینه) آخرین **Release** مخزن رسمی
  [AmirGhl/Yar](https://github.com/AmirGhl/Yar) را می‌سنجد (برای fork خودتان، نشانی‌اش را در تنظیمات بنویسید)؛ اگر مخزن هنوز
  Release نداشت، `manifest.json` شاخهٔ اصلی را.
- نسخهٔ تازه که پیدا شد: **توست** «نسخهٔ تازهٔ یار آماده است — جزئیات»، دکمهٔ برجستهٔ **«نسخهٔ تازه»**
  بالای صفحه، نوار در **پاپ‌آپ**، و (اگر اجازه بدهید) **اعلان دسکتاپ** — برای هر نسخه فقط یک بار.
- پنجرهٔ «جزئیات»: تغییرات همان نسخه، دریافت zip، صفحهٔ انتشار، راهنمای سه‌قدمی نصب و دکمهٔ
  «بارگذاری دوباره»؛ و «یادم بینداز (فردا)» یا «این نسخه را نادیده بگیر».
- بعد از نصب نسخهٔ تازه، یک بار: «یار به نسخهٔ … به‌روز شد — تازه‌ها».
- **تنظیمات → به‌روزرسانی**: نسخهٔ نصب‌شده، مخزن گیت‌هاب، «بررسی کن»، بررسی خودکار و «خبرم کن».
- هیچ مجوز تازه‌ای لازم نیست: گیت‌هاب درخواست از هر مبدئی را می‌پذیرد.

> **چرا خودِ فایل‌ها را عوض نمی‌کند؟** کروم به هیچ افزونه‌ای اجازه نمی‌دهد فایل‌های خودش را
> بازنویسی کند. نسخهٔ نصب‌شده از فروشگاه کروم خودکار به‌روز می‌شود؛ برای نصب «باز» یار دانلود و
> مراحل را آماده می‌کند و نصب با یک کلیک «بارگذاری دوباره» تمام می‌شود — داده‌ها دست‌نخورده می‌مانند.

### تازه‌های نسخهٔ ۱٫۶

- **کلیدواژهٔ `yar` در نوار آدرس کروم** — بدون باز کردن تب جدید: `yar ۲۵×۴` حساب می‌کند،
  `yar ۱۰۰ دلار` به تومان تبدیل می‌کند، `yar کار خرید نان` کار اضافه می‌کند، `yar یادداشت …`
  یادداشت می‌سازد، و هر چیز دیگر با موتور پیش‌فرض جست‌وجو می‌شود (`!y` و بقیه هم کار می‌کنند).
- **منوی راست‌کلیک در همهٔ صفحه‌ها**: متن انتخاب‌شده → کارها یا یادداشت‌ها (با نشانی منبع)؛
  پیوند یا خود صفحه → میان‌برهای یار. یک «✓» کوتاه روی آیکون افزونه تأیید می‌کند.
- **دقیقه‌های تایمر روی آیکون افزونه** در نوار ابزار، حتی وقتی هیچ تب جدیدی باز نیست.
- **خوش‌آمد اولین نصب**: نام، شهر و تم در یک صفحه، به‌همراه سه راهنمای کوتاه. اختیاری است و
  فقط یک بار می‌آید.
- **جست‌وجو در تنظیمات**: «تم»، «اعلان» یا «نقره» بنویسید؛ فقط همان ردیف‌ها می‌مانند.
- **اخبار**: تیترهای خوانده‌شده کم‌رنگ می‌شوند و با چیپ‌های بالای فهرست فقط یک منبع را می‌بینید.
- **سریع‌تر و مقاوم‌تر**: زبانه‌های اخبار، نشان‌ها، مبدل و سبد تا دیده نشوند ساخته نمی‌شوند (درخواست
  شبکهٔ کمتر هنگام باز شدن تب). اگر یک بخش خطا بدهد، فقط جای خودش کارت خطا می‌آید و بقیهٔ صفحه سالم
  می‌ماند.

### تازه‌های نسخهٔ ۱٫۵

- **نقرهٔ داخلی، قیمت هر گرم**: نقرهٔ ۹۹۹ و ۹۲۵ (و انس جهانی نقره) در گروه تازهٔ «نقره» در نوار نرخ‌ها،
  مبدل و سبد. برای کاربران قبلی هم یک‌بار خودکار کنار طلا به نوار اضافه می‌شود. «۵ گرم نقره» در
  نوار جست‌وجو هم جواب می‌دهد.
- **جزئیات نماد**: کلیک روی هر نرخ، قیمت، تغییر امروز، کف و سقف روز و **نمودار روند ۷ روزه** را نشان
  می‌دهد. تاریخچه روی همین دستگاه ساخته می‌شود (هر ساعت یک نقطه، بیشینه ۷ روز).
- **هشدار قیمت**: «اگر نقره از ۵۲۰ هزار تومان بالاتر رفت خبرم کن». سرویس‌ورکر هر ۱۰ دقیقه می‌سنجد و
  حتی با تب بسته اعلان می‌دهد (مجوز اعلان اختیاری است؛ بدونش، داخل صفحه خبر می‌دهد). هر هشدار
  یک‌بار مصرف است تا با هر نوسان اعلان تکراری نیاید.
- **سبد دارایی**: سکه، طلا، نقره، ارز و رمزارزی که دارید با ارزش کل، تغییر امروز، سهم هر دارایی و —
  اگر قیمت خرید بدهید — سود و زیان.
- **حالت پنهان** (کلید `H`): اعداد سبد و نرخ‌ها، کارها و یادداشت‌ها محو می‌شوند؛ با بردن موس روی هر
  کدام دیده می‌شود. برای اشتراک صفحه یا جای شلوغ.
- **کیفیت هوا (AQI)**: اختیاری، با مجوز جداگانه. شاخص و دستهٔ رنگی در کارت امروز، و PM2.5 در پنجرهٔ
  پیش‌بینی.
- نوار نرخ‌ها وقتی تب باز است هر ۵ دقیقه خودش تازه می‌شود؛ ممیز اعداد همه‌جا «٫» فارسی شد.

### تازه‌های نسخهٔ ۱٫۴

- **تصویر روز بینگ** به‌عنوان پس‌زمینه (آخرین خانهٔ پس‌زمینه‌ها در تنظیمات). مجوز دسترسی به
  `bing.com` اختیاری است و فقط با همان کلیک خواسته می‌شود. نام عکس و اعتبار عکاس ریز کنار نام
  افزونه می‌آید. تصویر ۱۰۸۰ یا UHD بسته به نمایشگر انتخاب می‌شود و آخرین تصویر به یاد می‌ماند
  تا تب تازه یک لحظه هم خالی نباشد.
- **جابه‌جایی میان‌برها** با کشیدن (یا `Alt + ← →`)، با انیمیشن نرم. اولین جابه‌جایی ترتیب را
  ثابت می‌کند تا پرکاربردهای مرورگر دیگر به همش نریزند. کشیدن هر پیوند از بیرون روی شبکه،
  میان‌بر تازه می‌سازد.
- **یادداشت‌های چندتایی** (تا ۳۰ تا): سطر اول عنوان است، با یک کلیک یادداشت تازه، حذف با
  «برگرداندن»، همگام بین تب‌ها، و جست‌وجو در متن یادداشت‌ها از پالت فرمان. یادداشت قدیمی
  خودکار و بی‌کم‌وکاست به قالب تازه منتقل می‌شود.

### تازه‌های نسخهٔ ۱٫۳

- **پیش‌بینی آب‌وهوا**: احساس واقعی، رطوبت، باد، احتمال بارش، طلوع و غروب، ۱۲ ساعت آینده
  و نوار دمای ۶ روز روی بازهٔ کل هفته.
- **مبدل**: ارز و طلا و رمزارز ↔ تومان (دوطرفه) با نرخ زندهٔ نوار، و تاریخ شمسی ↔ میلادی + قمری.
- **تایمر**: صدای پایان (Web Audio، بدون فایل)، اعلان دسکتاپ اختیاری حتی با تب بسته،
  شمارش جلسه‌های امروز، شمارش معکوس روی عنوان تب، و همگام بین چند تب باز.
- **کارها**: ویرایش درجا (دوبار کلیک)، نوار پیشرفت و عدد کارهای مانده روی زبانه.
- **پشتیبان‌گیری**: همهٔ داده‌ها در یک فایل JSON، و بازیابی با اعتبارسنجی.

### میان‌برهای صفحه‌کلید

| کلید | کار |
| --- | --- |
| `Ctrl+K` | پالت فرمان |
| `/` | رفتن به جست‌وجو |
| `۱` … `۹` | زبانه‌های پنل کناری |
| `T` | تغییر تم |
| `H` | حالت پنهان |
| `?` | راهنمای میان‌برها |
| `yar` + فاصله | در نوار آدرس کروم: حساب، تبدیل، «کار …»، «یادداشت …» |
| `Alt + ← →` | جابه‌جا کردن میان‌بر انتخاب‌شده |
| `← →` | پیمایش زبانه‌ها و روزهای تقویم |

### چیدمان یک‌صفحه‌ای

صفحه هرگز اسکرول نمی‌خورد. چهار ناحیه، و بس:

```
┌───────────────────────────────────────────────────────────┐
│ یار                                             ☀  ⚙     │
├──────────────┬──────────────────────────┬─────────────────┤
│  ۱۴:۳۲  ☀۲۸° │                          │ ▣ ▤ ▥ ▦ ▧      │
│  جمعه ۳۰ مرداد│  ┌────────────────────┐  │                 │
│  روز طبیعت   │  │  جست‌وجو        🔍 │  │   کارها         │
│              │  └────────────────────┘  │                 │
│  ┌────────┐  │                          │   یادداشت       │
│  │ تقویم  │  │   ▣ ▣ ▣ ▣ ▣ ▣          │   اخبار …       │
│  └────────┘  │   ▣ ▣ + + + +          │                 │
├──────────────┴──────────────────────────┴─────────────────┤
│ 💵 دلار ۱۸۹,۴۰۰ ↑ · 🪙 سکه ۱۹۹,۵۴۰,۰۰۰ ↓ · ₿ …      ⚙  │
└───────────────────────────────────────────────────────────┘
```

**ساعت، تاریخ، آب‌وهوا و مناسبت یک کارت‌اند، نه چهارتا** — چون همیشه با هم خوانده
می‌شوند و چهار قاب جدا فقط مرز اضافه می‌ساخت.

**نرخ‌ها پنل ندارند.** یک نوار باریک پایین صفحه: آیکون گروه، نام ریز، عدد، جهت تغییر.

**هفت بخش کناری در یک کنترل بخش‌بخش‌اند.** فقط زبانهٔ فعال نامش را نشان می‌دهد؛
بقیه آیکون‌اند (نام کامل روی hover و برای صفحه‌خوان باقی است). با کلیدهای `۱` تا `۷`
جابه‌جا می‌شوید و با `/` مستقیم به جست‌وجو می‌روید.

**ابزارها ساکت‌اند.** دکمه‌های هر کارت و ریل بالا تا وقتی موس روی‌شان نرود کم‌رنگ‌اند.

وقتی ارتفاع کم می‌شود، چیزها به ترتیب مشخصی جمع می‌شوند — **اول فاصله‌ها، بعد
تزئینات، و آخر از همه اطلاعات**. زیر ۱۰۰۰ پیکسل پهنا، پنل کناری زیر بخش وسط می‌رود.
اگر ناحیه‌ای باز هم جا نشد، **خودِ آن ناحیه** اسکرول می‌خورد (با محو شدن لبه‌ها)، نه کل صفحه.

## ساختار

```
manifest.json              مانیفست نسخهٔ ۳
_locales/fa/               نام و توضیح افزونه
src/
  background/              سرویس‌ورکر — شبکه، نوار آدرس (yar)، منوی راست‌کلیک، نشان آیکون
  core/                    تنظیمات، ذخیره‌سازی، تم، حرکت، پیام‌رسانی، DOM، مجوزها، پشتیبان
  lib/                     تقویم‌ها، مناسبت‌ها، ماشین‌حساب، مبدل، متن، یادداشت‌ها، قالب‌بندی
  services/                آب‌وهوا، بازار، اخبار، پیشنهاد جست‌وجو، کش
  ui/                      کارت، زبانه‌ها، دیالوگ، پالت فرمان، پیش‌بینی، خوش‌آمد، حالت‌ها، توست
  ui/settings/             پوستهٔ کشوی تنظیمات + یک ماژول برای هر بخش (sections/)
  widgets/                 هر بخش یک ماژول مستقل
  styles/                  توکن‌ها، پایه، اجزا، چیدمان، ویجت‌ها، قابلیت‌های ۱٫۳
  assets/                  فونت وزیرمتن و آیکون‌ها
tools/                     ابزار توسعه (در بستهٔ نهایی لازم نیست)
```

هر ماژول یک مسئولیت دارد: `lib/` محاسبه می‌کند، `services/` داده می‌گیرد،
`widgets/` نمایش می‌دهد، `core/` حالت را نگه می‌دارد.

## داده‌ها و حریم خصوصی

هیچ داده‌ای به سرور ما فرستاده نمی‌شود — چون سروری در کار نیست. همهٔ تنظیمات، کارها،
یادداشت‌ها و میان‌برها فقط در `chrome.storage.local` روی همین دستگاه می‌مانند.

درخواست‌های بیرونی، همگی از سرویس‌ورکر و فقط به این مقصدها:

| مقصد | برای چه | چه می‌فرستد |
| --- | --- | --- |
| `api.open-meteo.com` | آب‌وهوا | طول و عرض جغرافیایی شهر انتخابی |
| `geocoding-api.open-meteo.com` | یافتن شهر | نام شهری که تایپ می‌کنید |
| `call.tgju.org` | نرخ ارز و طلا | چیزی نمی‌فرستد |
| `suggestqueries.google.com` | پیشنهاد جست‌وجو | عبارت در حال تایپ (از تنظیمات قابل خاموش کردن) |
| خبرخوان‌های فعال | تیتر اخبار | چیزی نمی‌فرستد |
| `air-quality-api.open-meteo.com` (اختیاری) | کیفیت هوا | طول و عرض جغرافیایی شهر — فقط اگر «کیفیت هوا» را روشن کنید |
| — (منوی راست‌کلیک) | افزودن به کارها/یادداشت/میان‌بر | هیچ — متن یا پیوند فقط روی همین دستگاه ذخیره می‌شود |
| `api.github.com`، `raw.githubusercontent.com` | بررسی نسخهٔ تازه | چیزی نمی‌فرستد — فقط نام مخزنی که در تنظیمات نوشته‌اید |
| `www.bing.com` (اختیاری) | تصویر روز | چیزی نمی‌فرستد — فقط وقتی «تصویر روز بینگ» را انتخاب کنید |

مبدل، ماشین‌حساب و جست‌وجو در نشان‌ها و یادداشت‌ها **هیچ درخواست شبکه‌ای ندارند**.
جست‌وجوهای اخیر و یادداشت‌های تقویم فقط روی همین دستگاه می‌مانند.

مجوز موقعیت مکانی فقط وقتی خواسته می‌شود که خودتان روی «استفاده از موقعیت من» بزنید،
افزودن خبرخوان دلخواه اجازهٔ دسترسی به همان دامنه را جداگانه می‌گیرد، و مجوز اعلان
(`notifications`) اختیاری است و فقط با روشن کردن «اعلان دسکتاپ» تایمر خواسته می‌شود.

پاسخ‌ها کش می‌شوند (بازار ۴ دقیقه، آب‌وهوا ۲۰ دقیقه، اخبار ۱۵ دقیقه). اگر سرویسی
پاسخ ندهد، آخرین دادهٔ ذخیره‌شده با نشان «آفلاین» نمایش داده می‌شود تا صفحه خالی نماند.

## توسعه

پیش‌نمایش در مرورگر معمولی، بدون نصب افزونه (APIهای کروم شبیه‌سازی می‌شوند):

```bash
npx --yes http-server . -p 5177 -c-1
```

سپس `http://localhost:5177/tools/preview/index.html` (تب جدید) یا
`.../popup.html` (پاپ‌آپ).

آزمون‌های محاسباتی (تقویم جلالی، ماشین‌حساب، مبدل، میان‌بر موتور، یکسان‌سازی متن،
تعطیلات پیش رو، یادداشت‌ها، جابه‌جایی، تصویر روز بینگ، تاریخچهٔ نرخ، هشدار قیمت، سبد دارایی،
کیفیت هوا و مهاجرت تنظیمات) + آزمون یکپارچهٔ سرویس‌ورکر (پیام‌ها، هشدار، نوار آدرس، منوی
راست‌کلیک و نشان آیکون — بدون مرورگر و بدون شبکه):

```bash
node tools/tests/run-all.mjs
```

یافتن ماژول‌هایی که بعد از بازسازی بی‌استفاده مانده‌اند:

```bash
python tools/check-orphans.py
```

ساخت دوبارهٔ آیکون‌ها:

```bash
python tools/make-icons.py
```

سنجش «یک صفحه بودن» در چند اندازهٔ نمایشگر — در کنسول پیش‌نمایش:

```js
await import('./fit-check.js'); await window.__yarFitCheck([[1920,1040],[1366,768],[1024,700]]);
```

خروجی برای هر اندازه باید `pageX: 0` و `pageY: 0` باشد.

### انتشار نسخهٔ تازه

۱. شمارهٔ `version` را در `manifest.json` بالا ببرید و بخش همان نسخه را در `CHANGELOG.md` بنویسید.
۲. برچسب بزنید و بفرستید:

```bash
git tag v1.7.0
```

```bash
git push origin v1.7.0
```

گردش‌کار `.github/workflows/release.yml` آزمون‌ها را اجرا می‌کند، بررسی می‌کند برچسب با نسخهٔ
manifest یکی باشد، `dist/yar-<نسخه>.zip` را می‌سازد و Release را با متن همان بخش CHANGELOG منتشر
می‌کند. یار کاربران تا چند ساعت بعد خبردار می‌شود.

ساخت بستهٔ نهایی (فقط فایل‌های لازم):

```bash
python tools/pack.py
```

- **تاریخ شمسی** با الگوریتم استاندارد جلالی محاسبه می‌شود و در بازهٔ ۱۳۸۰ تا ۱۴۲۰ رفت‌وبرگشت آن آزمون شده است.
